هذا المجلد يحتوي على النسخة الكاملة للموقع ولوحة التحكم، جاهزة للتشغيل والاستضافة والربط بدومينك.

---

## 1. بيانات تسجيل الدخول للوحة التحكم (`/admin` أو `/login.html`):
* **اسم المستخدم / البريد:** `moataz.emam.de@gmail.com` (أو `admin`)
* **كلمة المرور الافتراضية:** `Moataz@2026`
*(يمكنك تغييرها من ملف `server.js` أو عبر المتغيرات البيئية `ADMIN_PASS`)*

---

## 2. التجربة محلياً على جهازك:
افتح موجه الأوامر (Terminal أو PowerShell) داخل هذا المجلد واكتب:
```bash
node server.js
```
ثم افتح في المتصفح:
* **الموقع:** `http://localhost:3000`
* **لوحة التحكم:** `http://localhost:3000/admin`

---

## 3. خطوات الاستضافة المجانية 100% وربط الدومين:

بما أنك تمتلك حساب على **Cloudflare**، إليك أفضل وأبسط طريقتين للتشغيل المجاني الدائم:

### الطريقة الأولى: استضافة السيرفر المجاني على Render.com وربط الدومين عبر Cloudflare (الأسهل والأشمل)
1. قم برفع هذا المجلد إلى مستودع خاص بك على **GitHub** (مثلاً باسم `moataz-studio`).
2. سجل في [Render.com](https://render.com) مجاناً بواسطة حساب GitHub.
3. اضغط **New +** ثم اختر **Web Service**.
4. اختر المستودع الخاص بك:
   * **Build Command:** اتركه فارغاً أو اكتب `echo ok`
   * **Start Command:** اكتب `node server.js`
   * **Plan:** اختر **Free**
5. بعد دقائق سيعطيك رابطاً شغالاً لموقعك (مثل `moataz-studio.onrender.com`).
6. **ربط الدومين:**
   * في لوحة تحكم Render اذهب إلى **Settings** > **Custom Domains** وأضف دومينك (مثال: `moatazemam.com`).
   * سيعطيك Render سجل CNAME أو DNS.
   * افتح حسابك في **Cloudflare** واذهب إلى قسم **DNS** الخاص بدومينك وأضف سجل الـ CNAME المعطى لك وفعّل الـ Proxy (الأيقونة البرتقالية).
   * سيعمل الموقع على دومينك مباشرة مع شهادة SSL مشفرة وتخزين كاش وحماية مجانية!

---

### الطريقة الثانية: نفق Cloudflare المباشر (Cloudflare Tunnel)
إذا كنت تريد تشغيل السيرفر من جهازك الشخصي أو سيرفر منزلي وربطه بدومينك على Cloudflare بدون دفع أي تكلفة استضافة إطلاقاً:
1. من لوحة Cloudflare، اذهب إلى **Zero Trust** > **Networks** > **Tunnels**.
2. أنشئ نفقاً جديداً (Create Tunnel)، وقم بتثبيت مشغل Cloudflare السريع (`cloudflared`).
3. وجّه النفق إلى المنفذ المحلي: `http://localhost:3000`.
4. اربطه بدومينك بضغطة زر واحدة وسيصبح متاحاً للعالم فوراً.
